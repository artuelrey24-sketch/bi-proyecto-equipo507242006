 Proyecto de Business Intelligence - Comercial Andina S.A.S.

¿De qué trata el proyecto?

En este proyecto quiero proponer una solución de Business Intelligence para Comercial Andina S.A.S., una empresa ficticia dedicada a la venta de productos de consumo diario. Elegí este caso porque permite trabajar con información de ventas y analizar cómo se puede utilizar para mejorar las decisiones de un negocio.

La idea es organizar los datos para conocer cuánto vende la empresa, cuáles son sus costos, qué productos generan mejores resultados y cómo se puede mejorar el control del inventario.

 Objetivos del proyecto

- Analizar las ventas de las diferentes tiendas.
- Identificar los productos que más se venden y los que generan mejores ganancias.
- Organizar la información para que sea más fácil de consultar.
- Utilizar datos del DANE para complementar el análisis del comercio y los cambios en los precios.

Fuentes de información

Para desarrollar el proyecto, tengo previsto utilizar las siguientes fuentes:

- Ventas: datos ficticios que crearé para representar las ventas de la empresa.
- Encuesta Anual de Comercio del DANE: información para conocer mejor el comportamiento del comercio en Colombia.
- Índice de Precios al Consumidor (IPC) del DANE: datos que utilizaré para observar cómo cambian los precios con el tiempo.

 Herramientas propuestas

Para desarrollar la solución, propongo utilizar las siguientes herramientas:

- **Python y Pandas:** para organizar los datos y revisar posibles errores.
- **PostgreSQL:** para almacenar la información en una base de datos.
- **Power BI:** para crear gráficos e informes que faciliten el análisis de los resultados.

 Avance del proyecto

En esta primera entrega estoy trabajando en el diagnóstico de la situación de la empresa y en el diseño de una propuesta para organizar su información. En las siguientes etapas desarrollaré la base de datos, prepararé los datos y elaboraré los informes correspondientes.
